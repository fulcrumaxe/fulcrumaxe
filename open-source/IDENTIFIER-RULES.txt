# only the bare patterns the public plane needs to enforce, with no
# elaboration.

# Format matches what scripts/check-forbidden-identifiers.sh parses:
# === SECTION_START === / === SECTION_END === blocks, `#`-comments and
# blank lines ignored inside a block, {TOKEN} filled from IDENTITIES.

# self-skipped on its own absence and reported green.

# at runtime if present. That script (and the two tests exercising it,
# tests/test_repo_target_gate.sh and tests/test_ci_ported_export_checks.sh)
# has its own pre-existing, unrelated defect independent of this change — a
# stale ALLOWLIST entry naming a path no longer in the tree — so wiring it
# live here would surface that defect as a side effect of this PR rather
# than fixing the guard this Discussion is about. Left named as a follow-up;
# see the PR description.
